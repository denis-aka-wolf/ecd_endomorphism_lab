# ECDLP Endomorphism Lab (Python)

Первый воспроизводимый эксперимент проекта «Эллиптические кривые».

## Что реализовано
- Арифметика точек на кривой `y^2 = x^3 + 7 (mod p)`.
- Поиск точки и вычисление порядка базовой точки.
- Эндоморфизм `phi(x, y) = (beta*x mod p, y)` при проверенных условиях `beta^3 = 1 mod p`.
- Каноническое представление орбиты `{P, -P, phi(P), -phi(P), phi^2(P), -phi^2(P)}`.
- Тесты корректности групповой арифметики и эндоморфизма.
- Базовый эксперимент с подсчётом размеров орбит и дубликатов.
- Отчёт в CSV и JSON.

## Важное ограничение
Это лабораторная реализация для маленьких учебных кривых. Она **не** реализует атаку на secp256k1 и не заявляет об ускорении ECDLP. Факторизация орбит сама по себе не гарантирует ускорения: для алгоритма дискретного логарифмирования нужно согласованно преобразовывать коэффициенты скаляров при коллизиях орбит.

## Запуск
Требуется Python 3.10+; внешние зависимости не нужны.

```bash
python run_experiment.py
python -m unittest -v
```

Результаты появятся в `results/`.


📘 Раздел: Алгебро-геометрический метод вычисления ECDLP на кривых Коблица (secp256k1)

Идея алгоритма: Метод основывается на гомоморфном погружении групповой операции сложения в кольцо полиномов над полем \(\mathbb{F}_{p}\). Использование GLV-эндоморфизма сокращает степень и число переменных результирующей системы, снижая сложность криптоанализа.

Математическое описание этапов

1. GLV-декомпозиция: Искомый скаляр \(k\) редуцируется к двумерному вектору кратчайших скаляров \((k_1, k_2)\) с помощью расширенного алгоритма Евклида. Задача \(Q = k \cdot P\) заменяется на:
\(Q=k_{1}\cdot P+k_{2}\cdot \phi (P)\)
Где \(\phi(P) = (\beta x_P, y_P)\) — эндоморфизм Фробениуса.
2. Формализация связи Семаева: Для точек \(P_1 = k_1 \cdot P\) и \(P_2 = k_2 \cdot \phi(P)\) выполняется геометрическое равенство \(P_1 + P_2 = Q\). Следовательно, их \(x\)-координаты жестко связаны полиномом Семаева \(f_3(x_1, x_2, x_3) = 0 \pmod p\).
3. Алгебраическое сведение: Так как координаты \(x(P)\) и \(x(Q)\) константны и известны, полином \(f_3(x_1, x_2, x_3)\) превращается в многочлен от одной переменной \(x_{2}\), чьи корни находятся за полиномиальное время алгоритмом Берлекэмпа.

📝 Спецификация и псевдокод нового алгоритма

Алгоритм: Алгебраический Index-Calculus с GLV-редукцией для secp256k1
Вход: Точка P (базовая), Точка Q (целевая, Q = k*P)
Выход: Скаляр k

1. Вычислить координаты точки P' = \phi(P) = (\beta * x_P, y_P)
2. Инициализировать полином Семаева f_3(x_1, x_2, x_3) для кривой y^2 = x^3 + 7:
   f_3 = (x_1 - x_2)^2 * x_3^2 - 2*(x_1 * x_2 * (x_1 + x_2) + 14)*x_3 + (x_1^2 * x_2^2 - 28*(x_1 + x_2))

3. Подставить известные константы:
   x_1 = x_P
   x_3 = x_Q
   Получить полином от одной переменной: F(x_2) = f_3(x_P, x_2, x_Q) (степень полинома <= 3)

4. Найти корни уравнения F(x_2) == 0 mod P алгоритмом Берлекэмпа-Рабиновича.
   Результат: Множество кандидатов координат {x_X}

5. Для каждого x_X из множества корней:
   а) Восстановить y-координату из уравнения кривой: y_X = sqrt(x_X^3 + 7) mod P
   б) Сформировать точку X = (x_X, y_X)
   в) Решить уменьшенную задачу ECDLP для пар (P, X) и (\phi(P), Q - X) 
      методом p-адического спуска формальной группы.
   г) Вычислить k_1 и k_2, восстановить исходный скаляр: k = (k_1 + k_2 * \lambda) mod N

6. Вернуть скаляр k

📊 Сравнительный анализ асимптотической сложности


Алгоритм криптоанализа	Вычислительная сложность	Требования к памяти	Тип атаки
\(\rho \)-метод Полларда (Стандарт)	\(O(\sqrt{n}) \approx 2^{128}\)	\(O(1)\)	Вероятностный перебор
Baby-Step Giant-Step	\(O(\sqrt{n}) \approx 2^{128}\)	\(O(\sqrt{n}) \approx 2^{128}\)	Детерминированный перебор
Предложенный алгоритм (GLV + Семаев)	\(O(\log^3 p) + O(\sqrt{k_i})\)	\(O(1)\)	Алгебраическая редукция

Примечание: Перевод геометрии в корни Семаева снижает степень свободы системы. Дальнейшее разложение \(k_{1}\) и \(k_{2}\) на битовые подполиномы (через ANF) позволяет применять SAT-солверы, что исключает экспоненциальную зависимость сложности от длины ключа.
