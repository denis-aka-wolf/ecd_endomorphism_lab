# ECDLP Endomorphism Lab (Python)

Первый воспроизводимый эксперимент проекта «Эллиптические кривые».

## Что реализовано
- Арифметика точек на кривой `y^2 = x^3 + 7 (mod p)`.
- Поиск точки и вычисление порядка базовой точки.
- Эндоморфизм `phi(x, y) = (beta*x mod p, y)` при проверенных условиях `beta^3 = 1 mod p`.
- Каноническое представление орбиты `{P, -P, phi(P), -phi(P), phi^2(P), -phi^2(P)}`.
- Тесты корректности групповой арифметики и эндоморфизма.
- Базовый эксперимент с подсчётом размеров орбит и дубликатов.
- Отчёт в CSV и JSON.

## Важное ограничение
Это лабораторная реализация для маленьких учебных кривых. Она **не** реализует атаку на secp256k1 и не заявляет об ускорении ECDLP. Факторизация орбит сама по себе не гарантирует ускорения: для алгоритма дискретного логарифмирования нужно согласованно преобразовывать коэффициенты скаляров при коллизиях орбит.

## Запуск
Требуется Python 3.10+; внешние зависимости не нужны.

```bash
python run_experiment.py
python -m unittest -v
```

Результаты появятся в `results/`.
