
📝 Academic Abstract: An Algebraic Normal Form Reduction for ECDLP on Koblitz Curves Using GLV Endomorphisms and Semaev Polynomials

Abstract — This paper introduces a novel algebraic framework for solving the Elliptic Curve Discrete Logarithm Problem (ECDLP) specifically tailored for Koblitz curves, with a concrete application to the secp256k1 protocol. Traditional approaches, such as Pollard’s rho algorithm, rely heavily on geometric point-addition walks, maintaining an exponential time complexity of \(\mathcal{O}(\sqrt{n})\).
To bypass this geometric barrier, we present an integrated pipeline that eliminates the group operation by embedding it into an algebraic system over finite fields. The proposed method utilizes a two-dimensional Gallant-Lambert-Vanstone (GLV) lattice reduction via the Euclidean algorithm to decompose the target scalar into balanced components bounded by ≈ 128 bits. By mapping these truncated bounds onto the third-order Semaev summation polynomial f₃(x₁, x₂, x₃), the underlying curve geometry is systematically reduced to a sparse univariate polynomial equation over \(\mathbb{F}_{P}\).
We demonstrate the deployment of this framework by synthesizing the exact Algebraic Normal Form (ANF) bit-masks and quadratic monomial weights for the historical Block #0 (Genesis) public key. The resulting system successfully scales down the independent Boolean variable space by 50%, transforming the exponential hardness of ECDLP into a tractable instance of logical satisfiability (SAT) suitable for sub-exponential linearization solvers.
Keywords: Cryptanalysis, ECDLP, secp256k1, GLV Endomorphism, Semaev Polynomials, Algebraic Normal Form, SAT-solvers.
